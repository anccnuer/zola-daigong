# 首页文章列表美化计划

## 1. 设计目标
根据用户提供的图片，实现按年份分组的文章列表，包含以下元素：
- 年份标题（大字号，粗体）
- 文章条目包含日期和标题
- 虚线分隔线
- 简洁的垂直布局
- 微妙的悬停效果

## 2. 布局结构
- 按年份分组显示文章
- 年份标题使用大字号和粗体
- 每篇文章条目包含日期和标题
- 文章条目之间用虚线分隔
- 整体采用垂直列表布局

## 3. 样式改进
- 年份标题：大字号、粗体、与下方文章有明显间距
- 文章条目：日期和标题同行，日期右对齐
- 分隔线：虚线样式，微妙的颜色
- 悬停效果：标题颜色变化
- 整体间距：合理的垂直间距

## 4. 实施步骤
1. 修改首页模板，实现按年份分组的文章列表
2. 更新CSS样式，添加年份标题样式
3. 实现文章条目的日期和标题布局
4. 添加虚线分隔线
5. 优化悬停效果
6. 确保响应式适配

## 5. 文件修改计划
- **`templates/index.html`**：修改首页模板，实现按年份分组
- **`static/css/style.css`**：更新样式，实现新的列表布局

通过以上改进，将使首页文章列表更加美观、有层次感，符合用户提供的设计参考。
