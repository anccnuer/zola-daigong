Zola是一个快速的静态网站生成器，使用Rust语言编写。它具有简单易用的特点，适合创建博客、文档等静态网站。

## 创建新文章

在posts目录下创建一个新的markdown文件，文件名以.md结尾。文件头部需要包含front matter，例如：

```yaml
+++
title = "文章标题"
date = 2026-01-03
draft = false
+++
```

## 文章内容格式

文章内容使用Markdown格式编写，支持以下特性：

- 标题（#、##、###等）
- 列表（有序和无序）
- 链接和图片
- 代码块
- 引用
- 表格

## 本地预览

使用以下命令启动开发服务器，在本地预览博客效果：

```bash
zola serve
```

## 构建生产版本

使用以下命令构建生产版本的博客：

```bash
zola build
```

构建后的静态文件将位于public目录中，可以部署到任何静态文件服务器上。

## 主题定制

Zola支持主题定制，你可以：

- 修改templates目录下的模板文件
- 修改static目录下的CSS样式
- 添加自定义JavaScript脚本

通过这些方法，你可以打造出属于自己的独特博客风格。
