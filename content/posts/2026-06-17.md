## 需求

**核心需求**：制作带表格的word文档（足球课教案）。

这是以前从没做过的，所以很想尝试。

**唯一限制**：尽量不花钱。众所周知，AI可以控制word制作各种表格，但是需要比较先进的模型，而且要用api，这就需要花money。

## 解决方案

遂**另辟蹊径**：

1. 先将带有表格的模板转化成html格式（不要样式，包括边框样式）
2. 让Mimo等agent参考模板，输出html格式（好处是全自动且限免）
3. 使用pandoc将html格式转化成docx格式

## 操作与细节

**【一】如何制作一个比较完美的模板**

首先，要确保docx文件不存在格式错误，比如单元格存在错误合并（我在这儿卡了许久😅），如有误，可以用一个比较邪修的方法，新建一个excel，将word中的表格复制到excel里。在excel里调整好单元格的合并，然后再粘贴到word文档中。完美收工。

接下来直接将docx格式文档发给Deepseek，提示词如下：

```
帮我把这个word文档转成html，保留内容和表格结构，
尤其是不要将合并起来的单元格信息丢掉，去掉样式
```

这时候，D老师给的结果可能还有问题，比如有些合并起来的单元格，在输出结果中可能并未合并起来，可以使用以下提示词进行微调：

```
请更改，第一行为教学内容（一格），空（剩下的格，合并）；
第二行为教学目标（一格），空（剩下的格，合并）
```

我的提示词其实还存在挺大的问题，我认为普适性不强，全靠D老师NB。但终归还是得到了一个看起来能用的模板。

**【二】为什么不要样式**

因外但凡加入了边框样式，转化出来的word文档中，表格的边框都会变成诡异的双边框。

**【三】pandoc转出来的word表格怎么没有边框**

```bash
# 先生成参考文档
pandoc --print-default-data-file reference.docx > custom-reference.docx
# 使用ms word更改表格样式（Table，系统级样式，而不是修改文档里表格的样式）
# 在正常转换的命令后添加参数
pandoc input.html -o output.docx --reference-doc=custom-reference.docx
```
