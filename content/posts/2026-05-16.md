## 故障

昨天某台电脑开机后**黑屏**，但是**能显示鼠标**和某管家的悬浮球，我负责修理。这个故障其实我一年前见过，之前也成功解决了。可是也许过了太久了，我已经忘记了当时是如何解决的。我手忙脚乱，场面一度很尴尬。经此一役，我认为确实有必要记录一下。

## 方案

在网络上搜索，其实很多的答案并没有什么用。最常见的那个：打开任务管理器，运行explorer.exe。完全没有效果。最终在知乎上找到了一个[帖子](https://zhuanlan.zhihu.com/p/1962932163688236033)，这个帖子提供的方法很实用。

步骤如下：

1. 【Ctrl+Shift+Esc】打开任务管理器
2. 文件 ⇨ 运行新任务 ⇨ msconfig，勾选“以系统管理员权限创建此任务”
3. 选择“有选择的启动”选项，取消勾选“加载启动项”，然后点击“应用”

这时系统会提示重启，重启后一般可以正常显示。

## 推测

我认为问题的根源是某些国产垃圾软件，互相倾轧，争夺资源，导致explorer进程无法启动。所以正常启动之后只需要把系统中看起来奇奇怪怪的软件都卸载掉，应该就可以避免再次出现黑屏的情况。

在查找方案的过程中，又学了一招，【Ctrl + Shift + Win + B】，可以强制重置显卡驱动，解决卡死、黑屏、花屏、闪烁。当然如果不是显卡问题，这个快捷键也没啥用。

另外，我认为这个问题还可以通过进入安全模式来解决，我借助AI构想了一个可能有用的方案，但未尝试，先记下来，后面再遇到这类情况可以试一试。

```cmd
# 最小安全模式
bcdedit /set {default} safeboot minimal
# 带网络的安全模式
bcdedit /set {default} safeboot network
# 立即重启
shutdown /r /t 0
# 退出安全模式
bcdedit /deletevalue {default} safeboot
```
